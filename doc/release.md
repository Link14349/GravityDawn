# 引力破晓 — Gravity Dawn v1.0.0

首个正式版本。包含九章 36 个战役关卡、三章 23 个旧版关卡、七种弹药、中文任务简报与引导、三星评价及浏览器本地存档。

本次发布整理生产构建与分发流程，保留现有游戏玩法和关卡数据。正式包内的关卡、图片和脚本全部随包提供，运行时无需联网获取资源。

## 运行正式包

解压 `gravity-dawn-1.0.0.tar.gz`，进入 `gravity-dawn-1.0.0` 目录。安装 Node.js 20.9 或以上版本后运行：

```bash
node src/serve-release.cjs
```

浏览器打开 `http://127.0.0.1:4173/`。无需安装 npm 依赖。用 `PORT=8080 node src/serve-release.cjs` 更换端口；需要局域网访问时设置 `HOST=0.0.0.0`。按 Ctrl+C 停止。

也可把 `dist/` 中的全部内容上传到静态 HTTP(S) 网站，支持域名根目录或以 `/` 结尾的子目录。请通过 HTTP(S) 访问；不支持直接双击 HTML 的 `file://` 方式。正式包不包含关卡编辑器、阶段演示和源映射。

## 操作与存档

- 鼠标悬停弹体暂停，反向拖拽并松开发射；拖出 Δv 点线圈取消本次规划。
- 滚轮缩放，拖拽空白处移动镜头；空格暂停，时间滑动条支持 0.5× 至 20×。
- 根据弹体类型使用右键特殊能力；在飞行笔记中查看操作与任务提示。
- 星级和最高分保存在当前浏览器的网站存储中。升级沿用关卡 ID 与旧版存档映射；更换域名、协议或端口会使用独立存档。

推荐使用带鼠标的桌面浏览器；窄窗口有自适应布局，操作仍以鼠标为主。

## 从源码构建

在源码仓库执行：

```bash
npm ci
npm run release
```

`release` 依次执行全部 36 关的生产模拟回放和回归检查、Webpack 生产构建、发布打包。打包需要系统 `tar` 命令，失败时命令以非零状态退出。输出为 `releases/gravity-dawn-1.0.0.tar.gz` 及同名 `.sha256` 校验文件；`dist/release.json` 记录稳定版本号与各资源 SHA-256。压缩包自身时间戳可随打包时间变化，应以随包校验文件为准。

单独运行 `npm run build` 只更新 `dist/`；`npm run preview` 使用只读服务器预览该目录。Webpack 正式构建仅打包游戏入口，脚本文件名含内容哈希，并自动按运行目录加载资源。开发命令 `npm start` 保留阶段演示和设计器入口。原 `server.js` 提供编辑器保存接口，仅用于本地关卡制作，不作为正式包服务器。

阶段二十三演示位于 `http://localhost:8080/test/phase23-demo.html`，通过 webpack-dev-server 调用生产 `initGame()`。
