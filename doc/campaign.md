# 引力破晓：新战役设计与验证

## 目标与节奏

新战役共有 36 关、6 章，每章先引入一个概念，再组合已有技巧。所有文本资源使用中文，公式与快捷键保留标准记号。玩家可按顺序推进，也可以直接体验任意关卡。

初始关卡提供大目标、无引力干扰、备用弹体和拖拽方向图示；后续逐步引入引力强度、遮挡、移动目标、特殊载荷、多源引力与有限修正预算。每关有常驻任务目标、具体操作说明和策略提示，按 H 可隐藏或重新查看。六章首关各含两页可跳过的任务简报。

通关同时要求目标、分数和毁伤达标。1 星表示通关，2 星要求发射数量不超过 parShots，3 星再限制累计 Δv。各章每目标的三星 Δv 预算依次为 160、150、145、140、130、120。分裂产生的子弹不重复计入发射数量。

## 关卡可解性

运行 `npm run check:campaign`。验证器搜索鼠标可实现的反向拖拽，并在实际 `FlightSimulation` 中逐帧回放；该类也是主游戏使用的生产模拟。结果是全部 36 关存在满足通关条件的参考解，并非对所有玩法和三星解的穷举证明。关卡数据没有随机生成，重试恢复相同初始条件。

附加检查包含：每关 600 帧（10 秒）无操作时目标不消失、不自动过关；多次重试后的输入监听；缩放坐标；燃料不足时预测与实际燃烧一致；移动核心未来位置预测；稳定 ID 与旧 Cookie 存档迁移。参考解保存在 `campaign-validation.json`，包含发射帧、弹体序号、Δv 与得分，可用于回归对比。

生产构建还通过独立静态服务器加载并实际完成三星通关与弹体用尽后的失败结算。浏览器验证覆盖主界面、中文任务简报、真实拖拽发射和首关通关、结算到下一关、重试、空格暂停、刷新后进度、关卡档案与窄屏无横向溢出。旧版 23 关保持原布局和原评分，不属于新战役可解性验证的 36 关。

## 维护

新增关卡应保留稳定 id；章节索引决定展示顺序。修改轨道、碰撞尺寸、载荷、目标分数或通关条件后重新运行验证。旧版关卡使用 legacyKey 迁移原存档，不能按新屏幕索引重写旧键。
