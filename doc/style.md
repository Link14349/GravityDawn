# 引力破晓 — 美术风格设计

## 整体定调

太空冷色扁平风 — 现代扁平化 UI，冷色基调 + 高明度点缀色，营造深邃太空中的明亮科技感。

---

## 配色方案

| 用途 | 色值 | 说明 |
|------|------|------|
| 深空底色 | `#0a0e27` → `#141833` | 深蓝紫渐变，非纯黑 |
| 面板底色 | `rgba(14, 20, 50, 0.92)` | 半透明深蓝，毛玻璃感 |
| 主强调色 | `#5eeadb` | 冷青（按钮、标题、高亮） |
| 次强调色 | `#7c8aff` | 冷紫蓝（副标题、次要按钮） |
| 警示/CTA | `#ff6b6b` | 珊瑚红（关键操作、敌人标记） |
| 黄金点缀 | `#ffd93d` | 仅用于星级/通关/核心目标 |
| 正文 | `#e8ecf4` | 偏白冷灰 |
| 辅助文字 | `#6b7a9d` | 低饱和蓝灰 |

大面积冷色（蓝紫系），小面积亮色点缀（青/金/红），避免暖色泛滥。

---

## UI 风格

**毛玻璃 + 细线框**
- 面板：半透明深蓝底，模拟毛玻璃
- 边框：1px 细线，`rgba(94, 234, 219, 0.2)`
- 按钮：圆角 10px，悬停发光，主按钮用青、次按钮用透明描边
- 卡片：微圆角，半透明暗底，悬停边框变亮

**字体层级**
- 大标题：`bold 48px` / 青
- 副标题：`22px` / 紫蓝
- 正文：`15px` / 浅灰
- 说明：`12px` / 暗灰

**动效（后续）**
- 按钮悬停：0.2s 过渡色变
- 面板切换：淡入淡出 0.3s
- 星级评价：逐个弹出

---

## 游戏内素材

**星体** — 纯色+径向渐变+光晕，扁平无纹理
**建筑** — 质点纯色圆，核心金色粗边，弹簧半透明白线
**子弹** — 未发射白描边，发射后消失；轨迹同色渐变
**敌人** — 绿色(正常)→紫色(受伤)
**爆炸** — 橙色冲击环+白色十字

## 排版

```
开始界面: 标题(青64px) + 副标题(紫蓝18px) + 剧情(灰14px) + 按钮(青)
选关界面: 标题(青28px) + 4列关卡卡片 + 返回(左下)
HUD顶栏: 关卡名(左) + 分数/子弹/退出(右)
结算界面: 居中面板, 通关/失败标题 + 分数明细 + 操作按钮
```
