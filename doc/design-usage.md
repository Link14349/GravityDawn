# 关卡设计器 — 使用指南

阶段十四引力战役使用建筑级参考轨道与公共材料参数，现有编辑器属性面板不包含这些字段。维护新战役请修改 `src/campaign-authoring.cjs`，运行 `npm run author:campaign` 后使用 `test/phase14-demo.html` 试玩，并执行 `npm run check:campaign`；不要在旧坐标模式中直接拖动这些局部坐标。下面的编辑器操作继续适用于原有单核心关卡格式。

## 启动

```bash
npm run dev
# 浏览器访问 http://localhost:8080/tools/design.html
```

## 界面布局

```
┌─ 顶部工具栏 ──────────────────────────────────────────────┐
│ [◎轨道] [●星体] [⬡核心] [·质点] [⬤敌人] [⏤弹簧] [⊡选择] │ ☑对齐网格 │ [▶测试] [导出] [导入] [新建] │
├─ Canvas 画布 ─────────────────────────┬─ 右侧属性面板 ─────┤
│                                       │ 选中物体后显示:      │
│   网格 + 星空背景                      │   名称/类型/坐标     │
│   轨道标记 + 虚线环                    │   轨道参数/质量/半径 │
│   星体 + 光晕                          │   颜色/分数/HP 等   │
│   建筑质点 + 弹簧                      │   [删除] 按钮       │
│                                       │                    │
├─ 底部状态栏 ──────────────────────────────────────────────┤
│ 工具: select | 选中: 恒星轨道#0 | 世界: (600, 400) | 缩放: 75% │
└──────────────────────────────────────────────────────────┘
```

## 两种模式

### 编辑模式（初始）

所有物体静态，用于搭建场景。左侧点选工具后在画布上放置。

### 测试模式（点击 ▶ 测试）

复用完整游戏引擎，可悬停子弹暂停、拖拽发射、空格暂停、滚轮缩放。悬停或拖拽时的点线圈标记剩余 ΔV 上限，拖出圈外立即取消规划，不消耗燃料或点火次数。点击 ⏹ 停止测试回到编辑模式。

## 工具栏

| 工具 | 快捷键 | 点击画布效果 |
|------|--------|-------------|
| ◎ 轨道 | `1` | 放置 fixed 轨道（默认），在属性面板可改类型 |
| ● 星体 | `2` | 点击轨道放置星体 |
| ⬡ 核心 | `3` | 点击轨道放置建筑核心点 |
| · 质点 | `4` | 核心附近：相对放置；空白处：新建无核心建筑 |
| ⬤ 敌人 | `5` | 同上，但质点带 isEnemy + HP |
| ⏤ 弹簧 | `6` | 依次点击两个同建筑质点创建弹簧 |
| ⊡ 选择 | `0` | 点击选中，拖拽移动 fixed 轨道/非核心质点 |

## 鼠标操作

| 操作 | 效果 |
|------|------|
| 左键点击 | 当前工具的效果（放置/选中） |
| 左键拖拽空白 | 平移镜头 |
| 左键拖拽质点/fixed轨道 | 移动位置 |
| 右键单击 | 选中目标（所有工具下可用），同位置多次右键循环切换 |
| 右键拖拽 | 平移镜头（保持当前工具不变） |
| 滚轮 | 缩放镜头 |

## 属性编辑

点击右侧属性面板的字段即可编辑：

- **文本字段**：点击后直接键盘输入，Enter 确认，Tab 跳到下一字段，Esc 取消
- **下拉字段**（类型/父轨道/轨道等）：点击弹出选项列表，再点击选择

## 物体类型与属性

### 轨道
| 属性 | 说明 |
|------|------|
| 名称 | 显示用，如「恒星轨道」 |
| 类型 | fixed / circular / elliptical |
| 父轨道 | 绑定到另一轨道下（子轨道坐标 = 父 + 自身偏移） |
| X/Y (偏移) | 相对父轨道的圆心偏移（fixed 类型则为世界坐标） |
| 半径/周期/相位 | circular/elliptical 专属，相位用角度（0°–360°） |

### 星体
| 属性 | 说明 |
|------|------|
| 质量 | 引力质量，值越大引力越强 |
| 半径 | 渲染半径（像素） |
| 碰撞半径 | 碰撞检测半径（默认等于渲染半径） |
| 颜色 | hex 色值，如 `#ffbb33` |
| 名称 | 画面上方显示的名字 |
| 轨道 | 所属轨道 |

### 建筑质点
| 属性 | 说明 |
|------|------|
| 质量 | 质点质量 |
| 半径 | 碰撞/渲染半径 |
| 分数 | 摧毁得分 |
| 颜色 | 渲染颜色 |
| 重要目标 | 是否必须摧毁（影响通关条件） |
| 轨道 | 核心点专属，绑定轨道 |
| 爆炸半径/冲量 | 摧毁时的爆炸效果 |
| HP | 敌人专属，生命值 |

### 弹簧
| 属性 | 说明 |
|------|------|
| 端点A/B | 连接的两个质点索引 |
| 劲度系数 | 胡克定律 k 值 |
| 阻尼 | 速度阻尼系数 |
| 断裂张力 | 超过此张力弹簧断裂 |

## 导出/导入

- **导出**：生成 levels.json 格式并复制到剪贴板（也可自动下载为 .json 文件）
- **导入**：粘贴 JSON 到弹窗中，支持单关卡对象或数组的第一个元素

## 对齐网格

勾选工具栏 ☑对齐网格 后，所有左键放置操作的坐标会自动吸附到最近的 100px 网格点。
