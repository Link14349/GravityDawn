# 引力破晓 — 剧情梗概

## 世界观

银河系外环的**桃子星系**盛产「**桃晶**」——一种蕴含巨大能量的稀有矿石，是星际文明赖以生存的能源命脉。桃子联邦世代守护着这片星域，依靠桃晶维持着繁荣与和平。

暗域军阀**雷蒙王**率领他的移动要塞「**赤暗号**」突袭了桃子星系。他摧毁了轨道防御站，夺走了维系整个星系能源网络的**桃晶核心密钥**。没有核心密钥，桃子星系的能源将在数月内彻底枯竭。更糟的是，雷蒙王将联邦顶尖的科研团队掳走，分散囚禁在他设立于星系各处的据点中，逼迫他们为他的战争机器效力。

## 主角

**桃子**——桃子联邦轨道防卫部队的年轻指挥官。她驾驶的是一台专为深空作战设计的轻型轨道战斗机「**晨星**」。晨星没有传统推进器，而是利用星体引力进行弹弓机动，将劣势转化为杀招。桃子的任务是：

- **收复据点**：一关一关摧毁雷蒙王设在桃子星系的军事据点
- **解救同僚**：每个据点中关押着科研人员，摧毁建筑救出他们
- **夺回碎片**：逐步收集被雷蒙王分散藏匿的桃晶碎片，为母星续命

## 反派

**雷蒙王**——来自银河暗域的征服者。他身形魁梧，披挂暗红色重甲，坐镇「赤暗号」指挥全局。他极度自负，坚信武力可以碾压一切，将桃子星系的防御视为不值一提的障碍。他把俘获的科学家锁在自己的据点里，得意于用敌人的智慧武装自己。

## 主线结构

| 阶段 | 内容 |
|------|------|
| 序幕 | 雷蒙王突袭，桃晶核心被盗，桃子紧急出击 |
| 第1-3关 | 收复外围据点，破坏雷蒙的前哨站，救出首批科学家 |
| 第4-6关 | 深入雷蒙占领区，摧毁重型防御设施，回收桃晶碎片 |
| 第7关 | 攻入「赤暗号」移动要塞，直面雷蒙王，夺回核心密钥 |

## 情感核心

桃子不是一个人在战斗。每摧毁一个建筑、每救出一名人质、每回收一枚碎片，母星的光芒就亮一分。「引力破晓」的含义：在看似无法挣脱的引力深渊中，找到那一道穿透黑暗的曙光。
